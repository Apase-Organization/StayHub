# TSK-101 — guest inventory selection UI

Status: ACCEPTED
Reviewer: Controller scoped source/diff review; acceptance limited to the property-detail offer-selection UI.

## Delivered scope

- Property detail collects dates, payment mode, number of rooms and adults/child
  ages per room. It requests offer search and displays eligible/sold-out alternatives,
  room-night price basis and stay totals.
- Input changes clear stale offers and local selections; a 409 prompts a fresh search.
- It does not trust client amounts or submit a booking. Quote/consent/reconsent and
  payment-mode amount allocation are TSK-103/082; the old MVC checkout is not passed
  room type selections.
- No-date results remain indicative only and cannot be added to a date-bound
  selection. Whole-place requests are limited to one room by the offer service.
