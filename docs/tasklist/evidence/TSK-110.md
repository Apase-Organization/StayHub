wrong binding/count/expiry even if an injected test Clock is rewound.

CONFIRMED transition or proof this service verified a provider. Caller082 must
verify signature/merchant/reference/envelope/amount/currency, guard booking state

## Independent review correction — construction XID authority

Independent110review reported one HIGH blocker: a caller-supplied construction_xid
must not be trusted merely because the column has a txid_current() DEFAULT.
The initial passing26cases did not cover that SQL input. Added a PostgreSQL BEFORE
INSERT header trigger that **unconditionally** assigns NEW.construction_xid :=
txid_current(); foreign values are ignored, not trusted. Existing posted header/
line UPDATE/DELETE guards and line admission remain unchanged. V14/legacy untouched.

Regression `foreignConstructionXidCannotAuthorizeAnotherConnectionToAppendPostedLines`
uses two simultaneously open JDBC connections with distinct actual PostgreSQL
transaction IDs. B obtains and retains its real XID; A explicitly claims B's XID
in its header INSERT. The test requires the DB-returned construction_xid to be A's
actual XID, permits A's original balanced lines and commit, then attempts a balanced
two-line append from B. That append must fail immediately with SQLSTATE23514 and
the construction-boundary message (not a deferred imbalance). After B rolls back,
the complete original header and line rows must match their pre-append snapshots.
